# Неделя 13: проверка на «чистой» машине

Цель — убедиться, что проект поднимается без скрытых локальных пакетов и что тесты проходят.

## 1. Клонирование и виртуальное окружение

```bash
git clone <url-репозитория> SpendFlow
cd SpendFlow
python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
python -m pip install --upgrade pip
```

## 2. Зависимости

Приложение и все транзитивные версии:

```bash
pip install -r requirements.txt
```

Для запуска тестов:

```bash
pip install -r requirements-dev.txt
```

Альтернатива (как в репозитории): `pipenv install --dev` и далее `pipenv run pytest`.

## 3. Тесты (QA)

Из корня репозитория:

```bash
pytest
```

Ожидается: все тесты зелёные, без обращения к сети.

## 4. Запуск дашборда

```bash
streamlit run src/main.py
```

Нужны файл `data/raw/rules.json` и (после первого сохранения трат) опционально `spendflow.db` в корне — они создаются при работе приложения; `rules.json` уже в репозитории.

## 5. Что проверить глазами

- Страница открывается, метрики и блок правил работают.
- После `pytest` зафиксировать скрин или лог «X passed» для отчёта по лабораторной.
